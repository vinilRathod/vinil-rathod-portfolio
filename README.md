
# Vinil Rathod | Portfolio

Personal portfolio website showcasing my experience, technical expertise, and selected work as a Frontend Engineer.

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Features

- Responsive design
- Selected work and professional experience
- Technical expertise
- Contact section

## Run Locally

Clone the repository:

```bash
git clone https://github.com/vinilRathod/vinil-rathod-portfolio.git
```

Navigate to the project directory:

```bash
cd vinil-rathod-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build

```bash
npm run build
```
